Unit 3: Strings & Forms

String functions, HTML forms, GET/POST, registration & login with validation

PHP String Operations

Create, access, search, replace, and format strings. Built-in functions: strlen(), strpos(), str_replace(), strtoupper(), strtolower(), trim(), substr(), explode(), implode().

HTML Forms

Forms collect user input using <input>, <textarea>, <select> elements. Data is sent to the server for processing.

GET vs POST Methods

GET POST
Data visible in URLData hidden in request body
Limited data sizeLarge data size
Less secureMore secure

Server-side Validation

PHP validates form data on the server: check for empty fields, validate email format, verify password length, sanitize input using htmlspecialchars() and filter_var().

Student Registration

Form collects name, email, password. PHP validates all fields and stores valid data in the database.

Student Login

Form collects email and password. PHP verifies credentials against stored records and grants or denies access.
