Unit 4: PHP + MySQL

Database connectivity, CRUD operations, student system

MySQL Connectivity

PHP connects to MySQL using mysqli_connect(). Requires host, username, password, and database name.

Database & Table Creation

CREATE DATABASE creates a new database. CREATE TABLE defines tables with columns, data types, and constraints (PRIMARY KEY, AUTO_INCREMENT).

Inserting Data

INSERT INTO statement adds new rows to a table. Use mysqli_real_escape_string() to prevent SQL injection.

Retrieving Data

SELECT statement fetches data. mysqli_fetch_assoc() retrieves rows as associative arrays for display.

Data Manipulation

UPDATE modifies existing records. DELETE removes records. Both use WHERE clause to target specific rows.

Student System

Complete application: registration stores students in MySQL with hashed passwords, login verifies credentials using password_verify().
