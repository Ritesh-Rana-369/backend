TCP/IP, HTTP, DNS, SMTP, IP Addressing, HTML, JavaScript

Internet & TCP/IP

The Internet is a global network of interconnected computers. TCP/IP (Transmission Control Protocol/Internet Protocol) is the core communication protocol suite that enables data transmission across networks.

TCP: Ensures reliable, ordered delivery of data. IP: Handles addressing and routing of packets.

IP Addressing

Every device on a network has a unique IP address. IPv4 uses 32-bit addresses (e.g., 192.168.1.1), IPv6 uses 128-bit addresses.

HTTP Protocol

Hypertext Transfer Protocol defines how clients (browsers) and servers communicate. Common methods: GET, POST, PUT, DELETE.

DNS (Domain Name System)

DNS translates human-readable domain names (www.example.com) into IP addresses that computers use to identify each other.

SMTP

Simple Mail Transfer Protocol is used for sending emails between servers and from clients to servers.

HTML

HyperText Markup Language is the standard language for creating web pages. It structures content using tags like <html>, <body>, <h1>, <p>, <a>.

JavaScript Fundamentals

JavaScript is a client-side scripting language that adds interactivity to web pages. It runs in the browser and can manipulate the DOM.
