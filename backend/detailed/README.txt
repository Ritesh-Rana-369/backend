SETUP (XAMPP) - NO DATABASE NEEDED
1. Copy the "backend-syllabus-php" folder into C:/xampp/htdocs/
2. Start ONLY Apache in the XAMPP Control Panel (MySQL is not needed).
3. Website: http://localhost/backend-syllabus-php/
4. Admin:   http://localhost/backend-syllabus-php/admin/
All data is stored in data/syllabus.json (edited automatically by the admin panel).
