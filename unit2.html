Unit 2: PHP Basics

Syntax, variables, constants, data types, operators, decision making, looping

PHP Syntax

PHP code is enclosed within tags. It is a server-side scripting language embedded in HTML.

<?php echo "Hello World"; ?>

Variables & Constants

Variables start with $ (e.g., $name = "Rishi"). Constants are defined using define() and cannot change during execution.

Data Types

String, Integer, Float, Boolean, Array, Object, NULL. PHP is loosely typed — types are determined at runtime.

Operators & Expressions

Arithmetic (+, -, *, /, %), Assignment (=, +=), Comparison (==, !=, >, <), Logical (&&, ||, !).

Decision Making

if, if-else, else-if, and switch statements control program flow based on conditions.

Looping

for, while, do-while, and foreach loops repeat code blocks multiple times.

Mixing PHP with HTML

PHP can be embedded directly within HTML to generate dynamic content. PHP executes on the server before sending HTML to the browser.
